# Project: iphone2ipodapp
## What this is
An iOS app that lets parents lock down an old iPhone into a dumbphone/iPod by disabling most apps and allowing only a limited set like Apple Music or Tidal.

## How we work
- Files in docs/ are the project's memory
- README.md = what this is
- CHANGELOG.md = what's been built
- IDEAS.md = what's next
- DECISIONS.md = non-obvious choices and why
- At the end of every session: update docs/, commit, push.
- One change per prompt. Don't stack features.

## Tech
- Swift / SwiftUI
- iOS

## Always
- Before starting work, read docs/CHANGELOG.md
- When making a non-obvious choice, append it to docs/DECISIONS.md
